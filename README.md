💱 Currency Converter



A simple and responsive Currency Converter web application built using HTML, CSS, and JavaScript. Convert amounts between different currencies with an easy-to-use interface.



✨ Features



\- Convert between different currencies

\- Simple and user-friendly interface

\- Responsive design for different screen sizes

\- Real-time exchange rates (if supported by the configured API)

\- Instant conversion results



🛠️ Technologies Used



\- HTML5

\- CSS3

\- JavaScript

\- Exchange Rate API (if configured)

💻 Run Locally



1\. Clone this repository:



&#x20;  ```bash

&#x20;  git clone https://github.com/Nikhil-st/Currency-Converter.git

&#x20;  ```



2\. Open the project folder:



&#x20;  ```bash

&#x20;  cd Currency-Converter

&#x20;  ```



3\. Open `index.html` in your browser, or use the Live Server extension in VS Code.



🌐 Deployment — GitHub Pages



1\. Open the repository on GitHub.

2\. Go to Settings → Pages.

3\. Under Build and deployment, select Deploy from a branch.

4\. Select the `main` branch and the `/(root)` folder.

5\. Click Save.

6\. Wait for deployment to finish and copy the published website URL into the Live Demo section above.



Make sure `index.html` is in the repository root.
